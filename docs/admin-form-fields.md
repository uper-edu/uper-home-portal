# 管理表单：字段标识与保存

CRM、CMS和系统管理统一使用“字段名＋*”。表单顶部显示“* 为必填项”。无星号表示选填，不再添加选填后缀。

必填缺失时不能保存或更新，界面定位缺项，草稿保留；服务端继续执行原有校验。条件必填只在条件成立时校验。标签关联控件，原生输入使用 required，自定义必选下拉使用 aria-required，错误不得只用颜色表达。

本次不扩大必填范围：活动创建要求活动名称；推广链接按原规则要求来源、方式及客户语言；用户登录邮箱和角色职责说明仍可留空。资料批量编辑中“明确清空”及密码留空保持原值等语义保持不变。记录进展四项联系信息仍须明确选择，指定发生时间仍须完整日期及小时、分钟。

表单呈现复用 AdminField／AdminFieldLabel／AdminRequiredNote；AdminForm只执行提交前检查，不负责权限、业务写入、幂等或保存结果查询。现有保存机制保持不变。
