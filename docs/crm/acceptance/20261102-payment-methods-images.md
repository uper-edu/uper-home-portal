# 收款方式、私有凭证图片及分次付款验收

2026-11-02。本轮按用户确认的方案实施；临时隔离验收沿用本轮明确授权，仅模拟客户／账号／课程／款项，不复制3000数据，不真实发送通知。

## 结果

- 操作列的内容垂直居中、表头及按钮水平居中，保留40px点击区域。3000实测同行客户文字与操作按钮文字中心均为y=346，操作表头与按钮中心均为x=1193。
- 收款方式预置银行转账、QRIS、电子钱包、VA、银行卡、现金、其他，默认不选；按渠道显示真实所需的收款方及交易／收据编号。常见银行／钱包可选，其他机构可填写；收款方式和机构在一行，金额／时间及账号／编号分别双列。现金只要求收款人及收据编号，不展示银行字段。
- 选择方式不代表开通真实支付渠道，不调用银行、钱包或支付网关；旧自由文字方式和原说明保持原文。
- 普通到账、正常部分付款备注可留空。金额或已有收款信息纠正、超收、退款需要备注；退回和作废继续要求原因。前后端一致校验。
- 图片可预览、移除；JPG／PNG／WebP，每次最多3张、每张5MB、合计9MB；读取图片时阻止保存。选择时只留当前表单内存，款项保存时才与图片原件、流水、回执及审计一并提交；取消无孤立附件。
- 原件字节存于私有数据库表，不进公开CMS目录；账本、历史、回执和审计不含图片base64正文。图片只能从绑定的款项及当前客户权限访问；未登录、越权、跨客户及未绑定图片拒绝。读取响应private/no-store、nosniff，保留原文件字节及哈希；不做OCR或AI到账判断。
- 原登记与核验新增图片分别保留；作废及身份归并不删除原件或历史。
- 同一报名可分多笔付款，每笔金额、时间、渠道、图片独立；项目只占一行，汇总真实到账与剩余。未增加分期计划、自动催收、任务或Tier变化。
