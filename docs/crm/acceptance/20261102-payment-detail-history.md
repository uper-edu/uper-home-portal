# 收款详情、购买信息与支付历史

2026-11-02，本地3000。用户反馈部分收款和已收齐无法方便查看原付款，随后确认列表应先有详情，包含购买产品及必要业务信息。本轮只修复入口、只读信息展示及编辑往返，不改变收款保存、价格、权限、余额和筛选统计。

## 原因和调整

原列表在没有待核验付款时把行操作统一导向receive新款项表单，历史虽仍在账本中，但被表单遮住；已收齐又不在默认待处理范围，入口更难发现。

现在所有列表行统一“查看详情／View details／Lihat detail”，先打开右侧“收款详情”。未付款、部分收款及已收齐一致；需要收款时再从详情明确进入核验表单。原显式动作深链接仍受既有权限保护。

详情包含：

- 客户姓名、购买课程、课时、报名确认时间、当前销售负责人。
- 报名时确认的标准价、优惠及最终应收；不读取当前新报价或客户预算替代价格快照。原报名依据按需展开，无资料不补造。
- 应收、已核实到账、已退款、剩余应收，以及真实收款状态、待核验和超收提示。
- 本项目逐笔付款／退款的金额、状态、实际时间、渠道与机构；交易／收据编号、原备注、核验备注、私有图片、登记及核验人员／时间按需展开。
- 退回、作废原因及独立的变更历史。原记录不覆盖或删除，不能把别的项目款项混入详情。

取消未修改表单返回详情；有草稿时使用共享确认框，继续编辑保留输入，放弃后回详情。详情关闭返回原列表，保留筛选、页码和位置。已收齐可用“已收齐”或“全部记录”筛选打开，默认待处理范围不变。
