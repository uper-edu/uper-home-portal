# 统一报名应收清单与财务直接到账核验

## 最终行为

- 按报名项目一行展示，报名生成的应收不依赖销售提交付款，即可进入清单。默认“待处理”包括未收款、部分收款、应收未确定、仍有待核验付款／退款的项目；收齐且无待核验款项、无需收款且无待核验款项移出默认范围，全部记录仍可查。
- 列表展示客户、课程、应收、已核实到账、剩余应收、报名时间、销售负责人和真实收款状态。有退款／超收时补充金额，有待核验记录时单独显示数量，不将核验状态当成收款状态。一个项目多笔款项不重复占行，列表计数为报名项目数。
- 财务从“核验收款”直接填写实际金额、实际时间、收款方式、账户标识、流水及核验说明，点击“确认到账”。原销售待核验登记入口保留；已有待核验付款时先核对原记录，不另建直接到账记录。现有退款仍独立核验。
- 直接到账是一项原独立财务权限下的原子命令receive，登记、唯一流水、核验结果、历史、审计及结果回执一并提交或回滚。不扩大财务角色权限，不修改报名价格或客户业务状态。
- 金额、实际时刻、账户、流水及依据不默认补填。结果未知只查询原请求；客户／报名项目／款项／动作分别校验，其他项目回执不能冒充当前保存成功。
- 关闭保留筛选、页码和列表位置，草稿关闭确认和后台请求隔离保留；新增项目路由参数在离开模块时清除。
