## 已实现

| 操作 | 保存结果 |
|---|---|
| 添加进展 / Add progress / Tambah progres | 记录实际工作，按入口关联任务，不改变任务状态，不要求下一步安排 |
| 编辑任务 / Edit task / Edit tugas | 修改内容、执行时间及补充说明；改期须说明原因，原截止和逾期保留 |
| 关闭任务 / Close task / Tutup tugas | 明确完成或终止，填写结果／原因，确认所关联请求，不强制再创建任务 |
| 待安排 / Awaiting task planning / Menunggu penjadwalan tugas | 活跃且无未完成任务的客户进入任务筛选及需处理范围，沿用权限、计数、导出与筛选逻辑 |
| 本次新增购买信号 | 多选、逐项保留来源并累积去重；未选不清除旧信号 |

正式复查与联系限制仍使用既有联系安排事务，防止修改时间绕过客户约定。停止联系、身份核实、Owner限制和分类／HSK评分未调整。销售阶段拆分仍待确认。
