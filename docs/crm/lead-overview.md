# Lead客户概况与分析

## 页面与范围
集合管理型页面在列表顶部显示四项紧凑概况、默认展开的当前阶段分布、默认收起的联系与推进分析。销售与经理可查看相同的联系和阶段分析；范围由当前负责人及其他筛选和服务端权限共同决定。经理可另看当前负责人分组。营销来源质量、获客成本和活动转化分析仍属于营销活动中心，不在此页新增。

所有指标使用权限内的当前筛选客户。同一客户可属于多个指标，不是转化漏斗。图表下钻增加可见的指标条件或销售阶段条件，仍与其他筛选取交集；可通过条件标签或清空入口撤销。图表不会偷偷忽略自身的阶段筛选。导出使用相同参数和权限。当前客户卡仅清除指标条件，不清除其他筛选。

## 四项概况
- 当前客户：去重客户数。
- 首次联系未完成：有consultation类型未完成首次要求的客户数，多条要求按客户去重；附逾期人数，不计其他任务。未知期限仍算未完成，但不虚构逾期。
- 近7天客户互动：截至当前快照的过去168小时，至少一条已知实际客户互动；采用三条互动时间线中的客户轨道，排除销售录入和AI回复。未知或未来时间不进入窗口。
- 有效沟通覆盖：有已成立、未被修正排除的Connected联系记录的客户数／当前客户数。未接通与未回复不计有效沟通；时间未知不否定已记录的沟通事实，但不能用于时长。

## 时间与执行
首次实际主动联系从客户登记到最早销售主动联系实际发生时间；首次有效沟通从登记到最早Connected联系实际发生时间。采用自然经过时长，不冒充工作时间SLA。保存时间不替代实际发生时间。相关记录中有未知实际时间时不能确定最早顺序，排除该客户的首次时长；登记未知、发生在登记之前单独计数，不当成0。

分布边界：不足1小时、1小时至不足24小时、24小时及以上；不可计算另列，没有发生相应联系的客户不放入有效样本。距上次主动联系分布为不足1天、1至不足7天、7至不足30天、30天及以上、时间未知、暂无销售联系。边界只用于统计，不设置催办或任务。

首次要求按时处理保持现有firstFollowup.at和dueAt。分子为可判断且正常按时结束的客户数；分母为可判断的正常结束客户＋已到截止且仍未完成的客户。尚未到期不计分母；无效号码／异常结束单列，不冒充有效沟通。缺少时效证据不纳入比率。此处只改统计，不修改任何完成、期限、通知或保存规则。

阶段仅使用当前七阶段；不把旧阶段映射为新阶段，无法确定时独立显示未填写阶段。停留从明确的人工阶段生效时间起算，缺失时不使用保存时间回填。已报名与结束推进不进入进行中停留；暂缓独立展示，不自动判定停滞。不跨阶段混用一个平均数，样本数和未知数量随中位数同时展示。

## 交互与边界
- 所有可下钻按钮均支持鼠标和键盘；高亮表示当前筛选，不表示完成或未读。
- 同源联系修正采用effectiveContactRecords，重复／未发生联系不重复计数，保留原文。
- 切换指标即时更新列表、阶段及分析，查询期间保留旧内容并显示更新状态；旧响应不能覆盖新条件。
- 不改账号、权限、配置、Tier、首次要求完成口径或客户约定。不新增任务，不重放通知。
- 默认只在3000验证中文电脑端；本轮经明确授权补充英文、印尼文桌面抽样，移动端未测试。

指标下钻可叠加，多个指标条件之间为AND；选中项再次点击仅移除该项，不清空其他条件。人数与点击后的列表必须在同一范围一致。刷新时间不独立占行，右上角刷新按钮悬停或聚焦可查看，Escape可隐藏提示。刷新异常和重试仍保留。

桌面阶段分布将七阶段与未填写共八项合并为一行，保留语义颜色和人数，不使用漏斗箭头。

数据库日期对象与HTTP中的ISO时间使用相同统计口径；未来的有效截止时间不属于“期限未知”。该转换只影响读取和统计，不修改数据库期限。
