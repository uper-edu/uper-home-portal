## 已实现

1. 原期限逾期提醒与执行安排版本分开校验。单独任务菜单和跟进保存两条改期路径均保留已排队的原期限提醒，失效执行提醒仍取消。完成、取消、安排变更及记录不存在使用真实取消原因。
2. 新建或明确调整的任务标记timeReminderVersion=1。首次约定执行／复查按首次时间，到时与改期走同一路径；纯响应截止不虚构执行约定。旧记录不补标、不补生成首次到时事件；现有旧改期扫描保留。
3. 正式复查首次生成一个task.created；有效复查调整取消旧记录、建立新任务，生成一个task.rescheduled并关联旧任务ID。不存在“创建＋改期”双份事件。复查通知按英文、印尼文、中文呈现内部复查用途。
4. 普通复查的卡片、列表、时间轴及改期表单使用“新复查时间”，原复查时间保留。三语在线指南及需求文档同步。
