# 管理工作区颜色与状态执行规范

适用于CRM、CMS和系统管理，2026-10-27起作为实施和验收要求。公共营销网站配色独立。共享变量位于`src/components/admin-colors.css`；主题由`useAdminTheme`提供，每个工作区及浮层显式声明`data-theme`。模块可保留表面／布局变量，业务颜色映射到共享语义，不能自行复制相近值。

|语义|变量／颜色|使用边界|
|---|---|---|
|操作、选中、链接、焦点|action、selected、focus／青绿|表示可操作，不代表保存成功或意向；主按钮配on-action前景|
|明确正向结果|success／绿色|已接通／已回复、确认保存、报名、内容在线／账号启用；不证明付款或AI准确|
|处理中、信息|info／蓝色|请求处理中、推进阶段，不能引入未读／已读或待办|
|需留意、结果待确认|warning／低饱和琥珀|未回复、冲突、复核、时间未知、保存结果未知；不等于失败或催办|
|失败、逾期、限制／危险|danger／红色|明确失败、字段错误、号码异常、既有逾期；停止联系另配禁止图标和文字|
|AI处理方式|ai、ai-bg／低饱和紫色|只标记实际AI结果；不充当来源、采用成功或真实性等级|
|正文、无记录、历史、结束|text、muted／中性|只读保持可读；无记录不同于未知时间；未分配不染红|

同一色系只在各自带文字的业务语境中表达，不能跨维度推理。颜色用于文字、小标签或局部边线，不给整个客户／原文／整行染成风险色。原文引用高亮使用quote配对，与冲突琥珀区分。

## 业务映射与特别约定

- 联系结果复用CrmContactResult：Connected绿色、No Response琥珀、Wrong Number红色、无结果灰色；只着色结果。时间／渠道默认中性，hover或focus强调链接，结果颜色不被覆盖。来源与依据保持真实内容及键盘操作。
- 七阶段复用CrmSalesStage：待建立沟通中性；需求沟通中／方案确认中蓝；报名办理中青绿；已报名绿色；暂缓琥珀；结束推进中性灰。保留真实阶段名与历史，不映射歧义旧阶段。停止主动联系独立红色＋禁止图标，即使阶段为已报名也不自动解除。
- Tier统一中性，不使用红黄绿热度梯度；颜色不自动改Tier，不生成任务。事实里程碑不是意向热度。
- 首次联系复用CrmFirstContactCountdown：正常中性青灰、逾期浅红，数字略加粗；不显示秒、不闪烁，不新增临近预警。
- 保存复用CrmSaveFeedback：成功绿色；处理中蓝色；结果未知琥珀并先查询；明确失败红色。保留草稿及原事务，结果未知不自动重复提交。
- CMS在线与系统账号启用使用success，隐藏／非启用保持中性。明确错误另行提示，不创造发布状态。
- AI标识不应用于原文、纯人工填写、空提取或人工采用状态。冲突原因用琥珀；整理明确失败用红色；AI紫色不覆盖这些业务状态。
- 修正旧值使用可读的次要色，新值正常正文或适当加重；不把每次资料变化都视为错误。真实冲突、采用原因、原文和独立时间完整保留。
- 必填星号沿用标签色；实际校验失败才显示红色及具体文字。不能用红色预先染全部必填字段。
- 测评等级、分数不按客户好坏着红绿。题型正确／错误／跳过允许绿／红／灰并带数量文字，不更改评分规则。
- 阶段分布复用阶段色。其他图表允许分类紫色等分类色，但分类对应稳定、图例和数字齐全，不套AI标识；0与无数据明确区分。
- 身份核实入口复用CrmIdentityAction：待核实的首要操作采用warning前景／背景／边框配对的琥珀色、盾牌问号图标及明确文字，与普通青绿跟进操作区分。琥珀表示待核实，不等于逾期或失败；保留焦点轮廓及原权限。列表与客户头部一致。
- 身份比对的相符提示沿用青绿比对标识（不是账户合并成功），差异琥珀、信息不全灰，均保留文字和原值。

### 客户约定（#723）

完整列表、精简列表和Follow-up复用CrmListAgreements。有效约定超过原时刻／仅日期已过当天才用danger；未来24小时的具体时刻或仅日期的当天用warning，并有“约定临近／今天约定”文字。普通有效约定使用info蓝色日历标识，内容正文中性、具体时间适当加重；未约定时间为中性灰；无效时间使用warning及明确文字。临近／今天的标识与时间用warning，逾期用danger，不整条客户染色，不新增任务或修改通知；首次联系仍沿用原规范、不新增临近预警。Follow-up的有效约定全部展开，只保留一个标题，逐条显示内容、时间和必要状态；完整／精简客户列表同样全部展示有效约定，单一标题，取消“更多约定”入口，不截断约定内容。已履行／取消／改约旧记录不作为当前提醒。

## 交互状态与权限

|状态|执行要求|
|---|---|
|default|正文可读，状态带文字；链接保持可识别点击区域|
|hover|增强链接或控件提示，不覆盖子项业务结果色|
|focus|独立清晰轮廓，不仅靠背景；键盘同样可访问|
|selected|选中背景＋语义属性／当前文字；不能冒充hover或focus|
|disabled|仅暂不可操作或可满足前置条件，附原因；忙碌保留保存中反馈|
|readonly|正常可读文字，不整段降透明度，不冒充禁用控件|
|loading/error|区分处理中、未知和明确失败，保留具体解释及草稿|

“记录进展”统一复用progressActionState和CrmProgressAction：没有crm.followup能力或不具备当前客户操作范围时隐藏，不残留Tab焦点；可以按现有规则自己认领时显示禁用入口并说明“请先自己认领”；已获业务权限的经理不强加认领。保存中禁用并显示保存中。展示不替代服务端校验，不扩大授权。

## 配对与验收

每个语义色定义文字、背景和必要边框的浅深色组合。小状态文字普通对比度至少4.5:1；必要控件边界、图标和焦点至少3:1。装饰分隔线不机械套用控件标准。不得用营销主题变量覆盖这些语义配对；不能因为深色action是浅色就继续搭白字。

按本次影响选取3000中文桌面代表页面：Lead列表与四页签、进展／资料／阶段抽屉、营销活动、运营、CMS、系统管理。分别报告实际页面状态、组件状态矩阵与未验证项；不能为制造错误去改3000配置或发送通知。浅深色、hover／focus、权限可见性及数据保护分别验收，其他语言／设备按用户授权扩展。

参考：[颜色使用](https://www.w3.org/WAI/WCAG22/Understanding/use-of-color.html)、[文字对比度](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)、[非文字对比度](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)。

## 三语与列表短标签

状态、来源、依据、鼠标提示、无障碍名称及错误／结果未知反馈必须同步ZH／EN／ID。系统界面文案与客户原文分离，不能以自动翻译页面文字的方式改写姓名、自由文本、原问卷答案或补充／修正。固定文案使用crmUiText和现有模块词典，新增文案须有三语条目。列表短标签独立于详情／表单全称：Availability／Jadwal（上课时段）、Start／Mulai（计划开始）、Budget／Anggaran（课程总预算）、Concerns／Kendala（顾虑）。短标签保留字段含义，不改预算口径；不能通过截断原文或缩小字号来容纳标签。英文和印尼文保留独立标签列宽、值列对齐、长原文展开及四列比例。

三条互动时间线的标题由 `interactionTrackLabel` 统一提供：有效沟通／Conversation／Komunikasi，客户互动／Customer activity／Aktivitas pelanggan，销售联系／Sales outreach／Kontak sales。列表与跟进页不另造近义标题；具体发生时间和距今时长独立呈现，无记录的完整无障碍说明保留。
