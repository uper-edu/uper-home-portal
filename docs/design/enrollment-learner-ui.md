# 学员端报名界面规范

适用于公开课程目录、班次详情、申请、候补、转账与凭证，以及「我的报名」的列表和详情。报名状态和可执行操作沿用[报名业务规则](../requirements/enrollment-v1-release.md#生效规则)。

## 信息层级

| 信息 | 手机 / 桌面字号 | 字重 |
| --- | --- | --- |
| 页级标题 | 26 / 36 px | 735 |
| 班次名称 | 16 / 17 px | 680 / 720 |
| 区块标题 | 15 / 16 px | 700 |
| 正文、课表、姓名、报名编号 | 14 px | 400 |
| 字段标签和辅助说明 | 12 / 13 px | 400 |
| 截止时间等关键值 | 14 px | 650 |
| 主金额 | 20 / 22 px | 750 |
| 状态标签 | 12 px | 650 |
| 业务按钮和文字操作 | 14 px | 650 |

- 班次名称占用卡片内容宽度，状态放在类型行或另起一行。长班名按班型、时段和期数等词组换行。报名编号保留完整值，允许换行。
- 同一信息区突出一个主金额。字段标签用常规字重，状态同时用文字和颜色表达。字体层级适用于中、英、印尼三语。
- 「我的报名」详情由页面统一提供返回、标题和内容。已验证的报名邮箱在标题下方只显示一次，默认折叠，展示脱敏地址。点击返回后恢复列表分类、滚动位置和焦点。
- 付款和客服帮助页按来源返回。来自订单详情时回到同一笔订单，来自列表时回到原分类。来源入口仍可用时恢复滚动位置和焦点。

## 详情页操作

- 页底统一使用 [EnrollmentRecordActions](../../src/components/EnrollmentRecordLayout.tsx)。短页的操作区贴近页面底边，长页的操作区位于正文末尾并随页面滚动。没有可执行操作时省略操作区。
- 实心按钮用于该状态下最明确的下一步，每页最多一个。描边按钮用于次操作，有主操作时排在其左侧。取消候补、撤回需求等低强调文字按钮靠左。窄屏允许换行，保持文字操作、描边按钮、实心按钮的阅读顺序。
- 页面跳转用链接，原页修改、取消、撤回用按钮。说明或客服等与某一状态直接相关的链接放在对应说明旁。按钮和页底文字操作的最小点击高度为 44 px。
- 详情打开时读取当前状态。待核验、退款处理中等状态在切回标签页时重新读取。读取失败时保留已显示的状态，在说明旁提供「重试」。

| 详情状态 | 内容中的辅助入口 | 页底操作 |
| --- | --- | --- |
| 凭证待核验 | 在核验说明旁提供「联系销售或客服」 | 允许时显示描边「补交凭证」。等待期间省略实心按钮 |
| 部分到账 | 显示剩余应付和补款说明 | 收款资料就绪时实心「查看补款」，其余情况实心「联系销售运营」 |
| 选课需求等待匹配 | 显示已登记的条件 | 左侧文字「撤回需求」，右侧描边「修改需求」 |
| 选课需求有匹配 | 有多个结果时，各班次卡片提供自己的详情入口 | 仅有一个匹配班次时用实心「查看匹配班次」。保留修改和撤回操作 |
| 候补等待空位 | 说明等待及空位通知 | 左侧文字「取消候补」，右侧描边「查看其他班次」 |
| 候补已有空位 | 说明席位以提交时为准 | 左侧保留「取消候补」，右侧实心「申请这个班」 |

视觉验收检查短页和长页、按钮层级、键盘焦点和窄屏换行。交互验收使用模拟记录，核对跳转目标及操作在各状态下的可用性。
