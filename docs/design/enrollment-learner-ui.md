# 学员端报名界面规范

适用于公开课程目录、班次详情、申请、候补、转账与凭证，以及「我的报名」的列表和详情。报名状态、金额计算和操作条件以[报名业务规则](../requirements/enrollment-v1-release.md#生效规则)为准。

## 页面与详情入口

课程办理按「目录 → 详情 → 办理」分工。页面主操作的名称应与点击后实际发生的动作一致。

| 步骤 | 页面职责 | 操作与状态 |
| --- | --- | --- |
| 目录 | 浏览、筛选和比较课程，显示班名、关键事实、价格和已知状态 | 卡片标题和查看按钮进入同一详情。班课用「查看班次」，一对一用「查看课程」 |
| 详情 | 用标签和值清楚展示课程、师资、安排、费用及适用规则，课程介绍从关联课程读取 | 总价与一个办理主操作放在共享操作区。按实际状态显示「申请这个班」「加入候补」或「登记约课」。条件未就绪时说明原因 |
| 办理 | 概括所选课程，再填写必要资料和偏好，按需验证邮箱并明确提交 | 普通班申请和候补按各自状态检查。一对一在登记页选择方便的时段，确认登记后进入「我的报名」 |

普通班申请和一对一登记共用课程摘要、独立学费行、学员资料及底部操作的布局。一对一将方便的时段和补充说明放在学员资料之后。

跨页保留语言、推广来源和选课上下文。返回目录恢复筛选、定位和焦点。已有订单、候补和邮件续办链接可直接进入对应步骤。

| 页面 | 信息顺序 | 操作 |
| --- | --- | --- |
| 课程目录 | 班名、已知的教师类型、每周课表、首课、报名或空位状态、课程总价 | 班名和「查看班次」都进入详情。学员在详情核对价格和安排，再按实际状态申请或加入候补 |
| 一对一课程 | 级别、一对一、定制时间、教师类型、固定课时和课程总价 | 标题和「查看课程」进入详情。详情右上角用 WhatsApp 图标和「WhatsApp」，底栏显示总价和「登记约课」。登记页可编辑带入的时段偏好 |
| 我的报名 · 一对一约课 | 课程、学员、登记时的固定课时和总价、时段偏好、确认后的教师与上课安排 | 验证邮箱并确认登记后，在「选课需求」显示「待约课」。顾问确认后回显原记录，待约课可改时段或撤回 |
| 班次详情 | 平铺班次摘要、「班次信息」、课程介绍、开班与退款规则 | 页标题右侧用对话图标和「咨询」，进入带当前班次的 AI Chat。可申请或候补时，底栏显示金额和主操作 |
| 我的报名 · 需要你处理 | 记录类型、状态、班名或选课条件、当前要处理的信息，例如付款截止、补款金额或匹配数 | 标题链接进入详情。需要行动的记录在卡片底部最多显示一个主操作 |
| 我的报名 · 进行中 | 班名或选课条件、当前状态、进度说明 | 标题链接进入详情 |
| 我的报名 · 历史记录 | 班名或选课条件、结束状态及原因 | 默认收起，展开后通过标题链接进入详情 |
| 报名详情 | 平铺班次摘要、付款截止或收款进度等状态信息、「报名信息」。凭证待核验的「下一步」放在报名信息下方 | 付款、补款及其他状态操作放在页底。取消报名放在正文末尾 |

列表用卡片，详情用留白和细分隔线划分区块。详情的班名与状态在空间足够时同排，窄屏自然换行。状态同时用文字和颜色表达。长班名按班型、时段和期次等词组换行。

## 详情字段与排版

班次详情和报名详情的结构化信息使用同一套[字段行](../../src/components/EnrollmentRecordLayout.tsx)。左列是标签，右列是内容，两列分别左对齐。课程费用、付款截止、课表和报名信息的值从同一位置开始。完整保留报名编号，允许换行。课表、首课时间和付款截止保留 WIB。

- 「班次信息」按授课教师、每周课表、首课时间、开班状态（适用时）、班级规模、课时安排排列。有有效总价和节数时，「每节价格」放在最后。
- 课程目录在班名附近展示已知的教师类型。班次详情在「班次信息」首行展示教师姓名和已配置的教师类型，如「Ms Jasmine（印尼教师）」或「曹老师（中国外教）」。姓名未配置时仅展示已知类型。具备班次资料的报名详情使用「授课教师」字段。
- 已验证的报名邮箱使用脱敏地址，默认折叠。订单详情将它放在「报名信息」内，可展开换邮箱或退出。列表仍在顶部显示当前验证邮箱。

| 信息 | 手机 / 桌面字号 | 字重 |
| --- | --- | --- |
| 页级标题 | 26 / 36 px | 735 |
| 班次名称 | 16 / 17 px | 680 / 720 |
| 区块标题 | 15 / 16 px | 700 |
| 详情字段标签、一般字段值与正文 | 14 px | 400 |
| 辅助说明与非字段小标签 | 12 / 13 px | 400 |
| 状态标签 | 12 px | 650 |
| 主金额 | 20 / 22 px | 750 |
| 业务按钮和文字操作 | 14 px | 650 |

## 价格栏与状态操作

可申请或候补的班次详情，以及可付款或补款的订单详情，使用共享[金额操作栏](../../src/components/EnrollmentRecordLayout.tsx)。手机端固定在视口底部，为正文预留底部空间。左侧显示金额，右侧放一个主操作。

| 场景 | 金额栏 | 正文 |
| --- | --- | --- |
| 班次可申请或候补 | 直接显示课程总价。标准价高于总价时在下方划线显示。「课程总价」保留给读屏器 | 「每节价格」在班次信息末尾，省略单独的「课程费用」区 |
| 班次暂不可申请或报价待确认 | 省略金额操作栏 | 课程总价及适用的标准价，或报价待确认，放在「课程费用」区 |
| 待付款 | 显示「待付金额」和本单余额，右侧是「转账与凭证」 | 显示付款截止和符合条件的取消报名入口。确认弹窗要求至少选择一个原因或填写补充说明，默认聚焦「保留报名」。 |
| 部分到账且可补款 | 显示「剩余应付」和本单余额，右侧是「查看补款」 | 列出本单应付、已核实到账及适用的旧单抵扣 |
| 部分到账且需人工协助 | 省略金额操作栏 | 余额留在收款进度中，页底提供联系销售运营 |
| 凭证待核验、报名成功、退款、转班或超时 | 省略金额操作栏 | 显示该状态的进度、金额明细或后续说明，按业务条件展示操作 |

公开价格使用班次报价。待付金额和剩余应付使用本单应付减去已计入本单的款项。转班或退款金额使用对应业务记录。

普通详情页底复用同一份组件中的 `EnrollmentRecordActions`。短页的操作区贴近页底，长页的操作区随正文滚动。实心按钮指向当前最明确的下一步，每页最多一个。描边用于次操作。取消候补与撤回需求用低强调文字按钮。跳转使用链接，当前页的修改、取消和撤回使用按钮。按钮和页底文字操作的点击高度至少为 44 px。

| 状态 | 操作安排 |
| --- | --- |
| 凭证待核验 | 客服入口放在「下一步」旁。允许补交时，手机页底使用整行描边「补交凭证」 |
| 候补等待空位 | 页底提供「取消候补」和「查看其他班次」 |
| 候补已有空位 | 「申请这个班」为主操作，保留「取消候补」 |
| 选课需求等待匹配 | 提供「撤回需求」和「修改需求」 |
| 选课需求有匹配 | 多个结果各有自己的详情入口。只有一个结果时，页底提供主操作「查看匹配班次」。保留修改和撤回 |

## 返回与复验

- 从报名详情返回列表时恢复原分类、滚动位置和焦点。目标位于历史记录时，先自动展开再恢复焦点。
- 付款和客服帮助页按来源返回。来自订单详情时回到同一订单，来自列表时回到原分类。原入口仍可用时恢复滚动位置和焦点。
- 详情打开时读取当前状态。待核验、退款处理中等状态在切回标签页时重新读取。失败时保留已显示的状态，在说明旁提供重试。
- 验收用模拟记录检查字段对齐、窄屏换行、底栏与正文间距、金额口径、状态对应的操作、历史折叠和返回焦点。语言与设备范围按本次授权执行。

## 课程介绍

「课程与班次 → 课程 → 教学内容」按英文、印尼文和中文维护。班次详情从同级且已绑定的课程实时读取介绍。已存的班次历史文本用于兼容，创建班次时不再复制教学文案。公开课程目录摘要省略教学正文。

课程介绍依次显示「适合谁」「学完能做什么」「课程学什么」「怎么学、怎么练」。适合人群用一句话说明；学习成果用短列表；知识点和练习各用一个默认收起的区块。课堂练习与教材资源只写已核对的项目。

[HSK 1 三语样板](../../src/data/system-defaults/hsk1-course-introduction.json)以 HSK Overview 为底稿。三语逐条保留原稿的七项学习成果和三项进阶价值，开篇保留从第一堂课开口、逐步建立交流信心的说明。教材话题、交际活动与练习资源作为补充。词汇数量按教材口径展示，第 1 册的 400 多个常用词、300 多个汉字、40 多个语法项目及 20 个单元均为全册数据。课程实际覆盖量以核定教学计划为准。资源包括线上教材练习、HSK 模拟试题和课堂录像。[北京语言大学出版社教材说明](https://www.blcup.com/PInfo/index/787)

[HSK 2](../../src/data/system-defaults/hsk2-course-introduction.json) 和 [HSK 3](../../src/data/system-defaults/hsk3-course-introduction.json) 分别保留原稿的七项学习成果和三项进阶价值。[HSK 4](../../src/data/system-defaults/hsk4-course-introduction.json) 以一门课呈现两个可展开的阶段。4A、4B 各保留五项学习成果、三项进阶价值和三项教材重点。课程目标与教材全册数据各自注明。教学内容可在管理端按语言页签编辑，HSK 4 在同一课程内选择阶段。

教材数据由出版社的第 2、3 册说明及第 4 册教师用书核实。4B 保留高校、CSC 奖学金与就业方向，申请资格以目标项目的语言和其他条件为准。[第 2 册](https://www.blcup.com/EnPInfo/index/391) · [第 3 册](https://www.blcup.com/EnPInfo/index/234) · [第 4 册教师用书](https://file.purpleculture.net/file/pdfpreview/9787561945490.pdf) · [中国政府奖学金院校要求示例](https://study.cqu.edu.cn/info/1387/2793.htm)

HSK 1–4 的「怎么学、怎么练」均列出教材线上练习、HSK 模拟试题和课堂录像。HSK 4 将这三项放在课程总览，4A 和 4B 分别保留各自的专项练习。
