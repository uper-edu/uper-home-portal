# 管理端记录详情规范

适用于 CRM、CMS 和系统管理的记录详情。新增或改造记录详情时使用共享导航和操作区。持续处理多条记录的页面再使用记录侧栏。配置目录、表单弹层和公开站按照各自的现行规范。客户与商机是本轮样板，其他存量页面在各自改造时接入。

## 操作区

| 位置 | 规则 |
|---|---|
| 标题上方 | 用带去向的文字入口返回大列表，返回保留筛选、排序、分页和阅读位置。收起／展开侧栏及上一笔／下一笔也放在这一层。 |
| 标题右侧 | 使用 `CrmDetailActions`。页面根据当前职责和记录状态决定动作。最多一项主操作，常用的次操作放在左侧。只有一项时直接显示。低频操作适合放进更多操作，状态变化按业务替换动作。没有主要业务动作时可省略主按钮。 |
| 对应信息旁 | 订单核款、凭证查看等只作用于单项的操作放在该项旁。 |
| 弹窗或抽屉 | 提交、取消留在操作层内。关闭时恢复触发控件焦点。保存反馈就近显示或沿用共享反馈，不在页头插入新的内容行。 |

采用共享按钮及语义色。权限不足隐藏入口，可满足的业务前置条件禁用并解释。身份待核实沿用独立琥珀语义。界面展示沿用服务端权限与保存规则。

## 主标题与标题下方信息

- 新增或改造记录详情时，使用 `CrmRecordTitle` 呈现一个主标题，以及可选的状态和识别信息。补充信息紧跟标题并与标题左对齐，作为状态或说明文本呈现，保留下面各业务区块的标题层级。
- 补充区可省略。优先显示会影响当前判断的一个业务状态，再用一行次要文字补充必要的识别信息，如负责人、业务编号或所属记录。状态使用带文字的共享业务样式。识别信息使用 12–13px 的共享次要文字色，短字段之间用 `·` 分隔，空间不足时允许自然换行。
- 当前记录的关键状态与识别信息优先放在标题下，同一字段在本详情的摘要中只出现一次。摘要保留关联入口、下一步等独立信息。正文中的历史状态和单条业务记录保留其当时的上下文。缺失的可选字段省略，业务上有意义的「未分配」等状态按原口径显示。编号与姓名保留原值，固定标签提供中、英、印尼三语。
- 客户在姓名下显示当前阶段、负责人和客户编号。商机列表、侧栏和详情统一使用「学员姓名 · 课程级别」，无学员姓名时用客户姓名。商机标题下显示当前阶段和负责人，存在待核实身份时优先显示该状态。摘要保留关联客户和可执行的下一步。学员与关联客户姓名相同时，以客户编号提供跳转入口。当前有权查看的列表范围内出现同名同级商机时，列表、侧栏和详情标题下使用同一商机编号。编号优先用现有商机 ID 的末八位，末八位也相同时显示完整 ID。切换详情页签时保持识别信息的位置稳定。

## 右侧内容区

- 采用记录详情面板的共享表面、边框、标题留白与正文边距。摘要需要承载关联入口或下一步时，使用标题下的浅底区。
- 正文按实际业务信息分区，使用有语义的二级标题和分隔线。操作跟随对应记录。内容有多组且确实需要切换时再用页签。桌面两栏独立滚动时，右侧标题与摘要保持可见，重点记录只在正文内定位。

## 记录侧栏

- 使用 `CrmRecordSidebar`、`CrmRecordRow` 和 `CrmRecordFilters`。栏宽基准 320px，标题 16px，记录名 14px，辅助信息 12–13px。行块统一分隔、选中标记和可见键盘焦点，浅深色使用管理端语义变量。业务方提供记录名、负责人、业务状态及必要的本域信息。
- 标题显示匹配数，常驻搜索和带已选数量的筛选入口。次要条件在同一侧栏的限高浮层显示，展开不挤动记录或详情。复用共享下拉，条件即时生效，关闭保留条件。先由内层下拉处理 Esc，再关闭筛选并恢复焦点。
- 从大列表进入时沿用筛选与排序。两处使用同一份条件和结果规则，返回仍带上侧栏修改。沿用该列表已有的分页和位置恢复机制。
- 筛选排除当前记录时，授权仍有效的详情和草稿保持打开，并显示提示。切换记录或离开时沿用草稿确认流程。收到范围撤销及时清除不可访问数据。加载、失败、暂无符合条件和有结果分别呈现。
- 可用空间足够时两栏独立滚动，选中记录仅在必要时在侧栏内部定位。窄屏和低高度沿用记录工作区单视图及导航方式。样板验收包含搜索、筛选、切换、返回恢复、草稿、焦点和浅深色。

## 折叠内容与原文返回

- 页面内展开使用 `AdminDisclosure`，保留原生展开语义。鼠标、Enter 和空格均可展开或收起，焦点留在标题。表格回执、审计记录和账本处理详情用紧凑样式，独立说明区用面板样式。客户全景的时间轴卡片共用展开箭头，保留卡片布局和原有展开规则。
- 「发送记录」通过记录链接直达时只展开目标行的技术回执，再定位并聚焦该行。在列表内手动查看不改变状态筛选或页码。从客户全景打开对话后，通过标题操作区的「返回客户全景」恢复原筛选和搜索，再将焦点交回打开对话的原按钮。
