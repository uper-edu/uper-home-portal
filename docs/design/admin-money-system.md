# 货币金额显示规范

适用于系统生成的结构化金额。统一实现为 `src/utils/currency.ts`。

| 场景 | 格式 |
| --- | --- |
| 中文、英文，IDR整数金额 | Rp 2,000,000 |
| 印尼文，IDR整数金额 | Rp 2.000.000 |
| 中文、英文，带小数金额 | Rp 1,234.5 |
| 印尼文，带小数金额 | Rp 1.234,5 |
| 明确的零金额 | Rp 0 |
| 未知金额 | 使用字段现有的未确定／未填写状态，不转成0 |

- 带币种的金额调用 `formatCurrency(amount, language, currency)`。币种默认IDR，显示标识为Rp，标识与数字之间使用一个空格。
- USD、CNY等其他币种保留明确的币种代码，不根据语言推测或换算币种。
- 当表头或字段名已经明确币种时，可调用 `formatCurrencyNumber(amount, language)` 仅显示数字。
- 显示保留数值中的小数，不以千、万、百万或M替代完整金额，不改变应收、到账、退款及结算计算。
- 金额输入框保留原有数值输入和校验规则；不要把带千位分隔符的显示字符串写回数值字段。
- 客户原文、员工原始记录、历史通知原文和CMS自由文本保持原样。不解析或猜测文字中的金额，不批量改写原始内容。
- 系统生成的当前值、历史变更前后值、课程及报名价格、收退款、活动预算与汇总共用上述工具。
- 切换语言只改变显示方式，不改变金额、币种、权限或保存机制。
