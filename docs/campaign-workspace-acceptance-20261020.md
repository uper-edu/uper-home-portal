日期：2026-10-20。状态：独立环境内部验收完成，等待用户确认。没有更新本地3000、推送GitHub或部署服务器。

## 当前交付范围

| 层级 | 设计与业务边界 |
|---|---|
| 创建活动 | 第一步仅活动名称必填；一个名称按输入原文保存。新活动码使用camp-前缀；旧码不变。类型、开展形式、排期、地点、主办方及预算为补充信息，不决定推广链接身份。 |
| 添加推广链接 | 第二步独立选择来源、方式、客户语言和入口体验；一个活动可有多条推广链接。保存后展示链接和对应二维码。c标识活动，p标识该活动内已保存的推广入口；原始UTM证据保留。 |
| 首页与详情 | 首页为活动卡片与可折叠筛选统计；详情为可收起的左侧列表及推广链接、活动信息、推广物料、结果与客户四个页签。返回保留筛选和滚动上下文。 |
| 信息与卡片 | Type · Delivery format同行；排期合并日期和时间；展示已填写的主办方、计划预算及有效线上参会入口。预算未填写与明确为零分别显示。日期缺失不补造当天或午夜。 |
| 页面操作 | Campaign页头为创建活动、来源核实及刷新；Lead页头保留权限控制的当前结果导出及刷新。共用按钮组件、图标、焦点和深浅色状态。44px最小触控高度；长文案允许换行。 |
| 来源核实 | 未知c与已知c但p无效／不匹配分开核实。保留原始参数证据与作用范围，移除内层重复代码标题和客户数。保存结果仍反馈实际影响客户数。 |
| 推广物料 | 明确为模板草稿，不宣称AI生成。物料语言与员工界面语言、推广链接客户语言独立；不会因切换界面语言改写人工原文。 |
| 非活动来源 | 表示首次登记没有具体活动归因，不推断为自然搜索，也不将未知c自动归入该来源。内部历史标识不变。 |

英文、印尼文、中文同步覆盖创建、卡片、侧栏、四个页签、来源证据、验证错误、保存反馈、草稿保护和在线指南。活动名称、主办方、人工备注、原始来源参数保持原文；原有归因、权限、客户分类及HSK评分规则未因本轮展示与翻译改变。

在线指南保留系统说明／操作指南结构，更新获客概念图与七个Campaign操作节点，解释多链接、c／p／UTM、两类核实和模板草稿。正式目录、面包屑及章节标题保持一致；示例码明确作为示例。
