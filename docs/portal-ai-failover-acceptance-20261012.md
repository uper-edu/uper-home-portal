# 根目录 AI 故障切换测试修复与验收

日期：2026-10-12。范围：修复根目录九项 AI 测试失败，在独立数据库验证 OpenAI → DeepSeek；不修改真实 CRM 数据、不重启 3000 服务、不部署或同步 GitHub。

## 根因与改动

`tests/chatFailover.test.mjs` 使用旧 `/api/chat` 请求结构（`messages`），用于独立测试模型切换。它复制父进程的全部环境变量，包含验收运行显式配置的 `DATABASE_URL`。服务端在数据库存在时优先挂载持久聊天接口；该接口要求访客 Cookie、`conversationId`、`messageId` 和 `content`。因此请求提前失败，没有产生预期模型响应，九项断言一起失败。

修复：测试服务端子进程只接收 PATH、临时目录和必要测试标记；明确清空数据库连接，临时 `.env` 同样明确禁用数据库并只保存模拟 API 配置。加入 HTTP 200 与 SSE Content-Type 断言，防止把路由或身份错误误解为模型返回空文本。持久聊天验收另在真实 PostgreSQL 测试库完成。

此次没有改变生产模型顺序、聊天内容、HSK 评分规则或真实服务端凭据。
