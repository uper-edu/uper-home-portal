# CRM 三语与在线手册验收

日期：2026-10-13。

## 交付

CRM 登录、账号菜单、营销活动、客户筛选/工作列表/字段表、同页跟进/对话/资料/测评、销售运营七模块、通知策略/渠道/发送记录/审计及在线手册接入英文、印尼文、中文。登录页和顶部提供三个语言选项，偏好保存在当前网站的浏览器缓存；日期使用对应语言区域格式。

印尼文静态词典位于 `src/utils/crm-id.json`；动态文案保留插值变量。该翻译器仅用于系统展示文案，客户姓名、员工姓名、原始聊天、人工备注、活动名称及技术标识不自动翻译。语言切换不提交任何客户、策略或渠道变更。

在线手册以现行行为重新编写，包含十个章节及 21 个显示字段参考：客户工作区、账号权限、筛选/字段表、跟进任务、聊天转人工、测评依据、七模块销售运营、通知/渠道/审计、营销归因、日常排错。三种语言同步维护。移除旧手册中与当前实现不符的身份匹配、跟进和通知描述。

用户已明确授权使用项目配置的 OpenAI API 翻译静态文案。提交内容为界面文字，不含客户记录、聊天记录或凭据。翻译中发现的动态变量遗漏、数量文案、SLA 字段属性及通知独立双语写法已修正。
