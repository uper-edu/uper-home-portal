# CRM 统一筛选验收（2026-10-13）

> 历史功能验收摘要：已移除退役数据库的环境、启动／恢复步骤及专项测试结果。其余结果仅代表当次功能版本，不构成当前MySQL验收；现行配置与数据保护结论见[环境配置与验收基线](environment-configuration.md#mysql-迁移与验收基线)。

## 已完成

- 取消两组重复的全部线索导航。搜索、负责人、跟进任务、仅我未读和更多筛选合并在一个区域。
- CRM Leader 默认全部负责人；Sales 默认自己负责的全部客户，包含无待办客户。Tester 沿用 Leader 全量权限。
- 更多筛选按客户分类、联系情况、需求特征分组，保留原客户分组值与分类规则。客户分组、销售阶段、联系状态、跟进情形、授课方式和购买信号支持多选，提供选项搜索。
- 同字段 OR、跨字段 AND；收起后保留可删除条件标签。清除筛选显示权限内全部客户，恢复默认回到角色初始范围。
- 搜索仅匹配姓名、电话、邮箱及编号字段，不再搜索整个客户 JSON 或聊天正文。输入短暂延迟后生效，移除搜索立即清空条件。
- 负责人选项独立于当前筛选结果；未分配使用明确查询值，同时兼容旧接口 `owner=`。切换负责人不会修改客户归属。
- 统一由服务端在权限过滤后筛选及计算概览；匹配数量以客户计数，多个任务不重复计为多个客户。
- 今天到期按保存的运营时区和当天日期判断，包含今天已逾期但尚未完成的任务。逾期按有效未完成任务的实际截止时间判断。
- 已完成、取消及历史待确认任务不计入逾期。历史待办另有筛选，列表不把占位截止日期展示为已确认日期。
- 未首次联系、长期未联系、未回复待重试作为独立跟进情形；长期未联系必须有有效联系记录且达到配置的时长。
- 业务概览默认折叠，注明当前筛选结果。表格中的 Tier 也统一命名为客户分组。中英文分别显示，人名不自动翻译。
