# 时间轴销售记录关联任务展示验收

日期：2026-10-17。仅更新独立 4426 环境；不切换 3000，不推送、不部署服务器。

## 改动

- 时间轴根据已保存的 processingTaskId、完成任务 ID、taskId、新任务 ID 显示具体任务内容。
- 区分本次处理并保持待办、本次完成、补充依据、改期、新建、替代和取消；替代分别展示原任务与新任务。
- 当前状态与期限明确标记为“任务当前情况”，不伪装为当时状态；改期单独保留本次事件所记录的新时间。
- 普通笔记不附加猜测的任务；任务缺失时保留真实关联 ID 并提示详情暂不可用。旧记录没有任务关联时不按备注文字猜测。
- 修复按任务过滤时间轴遗漏“处理但未完成”记录；旧 follow-up log 的明确任务字段可参与展示。
- 同一个完成任务只显示一次，不重复堆叠已完成说明和任务引用。
- 英文、印尼文、中文及在线指南同步。没有数据库迁移或业务规则修改。
