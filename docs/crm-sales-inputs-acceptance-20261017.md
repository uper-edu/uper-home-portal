# CRM 三种销售输入形态验收（2026-10-17）

## 范围与结果

本轮按已确认样稿实现三种输入形态；仅更新独立本地测试服务 4426。没有切换 3000、推送 GitHub、部署服务器或发送真实通知。

- **轻量笔记**：在工作区直接输入并保存，保留原文，不计为联系，不完成任务。
- **专注编辑器**：记录联系及处理指定任务使用同一布局，客户／任务上下文、当前记录、任务结果、下一步安排分区呈现。编辑时隐藏浏览用概况、任务列表及历史，避免操作区堆叠。
- **上下文短操作**：新增、补充依据、改期、替代、取消等使用标准弹层。固定任务操作显示任务与时间含义，改期同时显示原时间与新时间。

具体任务入口固定该任务，无任务下拉或多选。结果只可选择“保持待处理”或“完成此任务”；普通记录联系入口不完成任何任务。服务器对显式处理上下文再次校验任务范围和版本；旧草稿中的其他任务 ID 被过滤。保留既有客户写入权限、分类／评分规则、有效任务要求、事务与通知关联规则。

英文、印尼文、中文界面及在线指南同步。客户姓名、对话、手写任务与备注保持原文。保存反馈切换语言后同步更新。

## 业务与交互结果

| 场景 | 结果 |
|---|---|
| 记笔记；离开并返回草稿 | 已保存原文；不关闭任务；放弃前确认 |
| 未选择联系结果 | 阻止保存，显示对应语言错误 |
| 普通未接通记录 | 完成任务 0，原三个开放任务不变 |
| 从预约任务进入，完成并安排下一次 | 只完成指定预约任务；创建新跟进；其他任务不变 |
| 具体任务选择保持待处理 | 保存进展但任务仍开放，其他任务不变 |
| 内部核实记录 | `recordKind=closure`，不记为客户联系，完成任务 0 |
| 同一已保存请求重试十次 | 返回已有结果，不重复记录或任务 |
| 注入一次 HTTP 503 | 草稿保留、原请求内容锁定；结果查询未发现后使用原请求重试，最终只一条记录 |
| 错配任务 ID／过期任务版本 | 服务端拒绝，没有静默处理其他任务 |
| 改期 | 新执行时间更新，原 due_at 保留；显示两种时间含义 |
| 新增、补充依据、替代、取消 | 浏览器提交与 MySQL核对通过；保留原任务历史及原因 |
| 其他销售客户、共享池写入 | 无越权；共享池可读但该模拟销售不能直接写跟进 |
| 空白短操作退出 | 不误报草稿；有修改退出需确认 |
| Escape、Tab 循环、继续编辑 | 弹层及草稿确认可操作，原输入保留 |
| 三语 × 390／768／1280px | 专注编辑器九组检查无整页横向溢出、无任务复选框，原文不变 |
| 浅深色、移动端笔记及改期 | 人工视觉复核通过；窄屏堆叠，按钮可见 |

已修复验收中发现的：日期输入与预览状态不同步、弹层被固定页头遮挡、前一次保存反馈残留、保存反馈切换语言不更新，以及未修改短操作误报草稿。
