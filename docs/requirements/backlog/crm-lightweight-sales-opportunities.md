# Todo：CRM轻量销售机会

- 记录日期：2026-10-30
- 状态：待细化／未实施；用户同意总体方向，本轮仅记录需求。
- 目标：区分客户关系与本次销售进展，支持复购而不增加三套客户工作区。
- 实施前须确认完整方案及迁移、权限、统计、通知口径；本文不授权代码变更或发布。

## 1. 要解决的问题

同一客户已报名HSK 2，又咨询HSK 3时，单一客户级销售阶段不能同时表达历史成交和当前销售进展。不能通过覆盖“已报名”为“需求沟通中”来丢失两次购买的语境，也不能为复购重复创建客户。

## 2. 已讨论的架构方向

- [ ] 保留统一客户档案，复用现有客户身份体系；不建立Customer、Lead、Opportunity三套独立列表或转换搬迁流程。
- [ ] 将七阶段归属于具体销售机会；客户级当前阶段未来仅作受控展示投影，不再作为多次购买的唯一事实来源。具体存储设计待确认。
- [ ] 客户关系摘要由有效业务事实呈现，不增加销售手工维护的生命周期状态机。
- [ ] 正式报名、核实付款、正在上课分别表达；不能从“已报名”推断“已付费”或“正在服务”。
- [ ] 测评、原问卷、对话和原文依据继续保留；客户级事实可供多个机会引用，不复制测评记录。
- [ ] 联系安排独立于机会阶段；结束机会不等于停止联系，新机会不能绕过联系限制。
- [ ] 报名事实逐步与阶段变更解耦，关联具体课程／机会；保持依据与审计记录，不通过反复切换阶段重复确认报名。

## 3. 机会创建与去重

以下为讨论形成的建议规则，触发资格和并发行为仍须在实施前细化。

| 场景 | 建议行为 |
| --- | --- |
| 首次成功提交正式问卷，形成可销售跟进的客户登记 | 自动创建首个机会；初始“待建立沟通”；课程未明确就保持未明确 |
| 仅浏览、匿名一般咨询、未提交问卷 | 不创建机会 |
| 已有未结束机会，再次问卷登记或继续咨询 | 默认延续原机会，不因重复进入新增机会 |
| 已报名后咨询新的购买需求 | 销售明确确认创建新机会，系统／AI不直接创建 |
| 原机会结束后重新咨询 | 销售判断恢复原机会或新建机会 |
| AI识别新的课程兴趣 | 仅作为判断依据，不自动创建机会或提高Tier |

- [ ] 将自动创建与首次登记保存纳入一致性／幂等设计；响应丢失、重复提交、原提交重试不能重复创建机会。
- [ ] 同一次购买的时间、价格或方案调整沿用原机会。
- [ ] 已完成购买后再次购买另一课程，建立新机会。
- [ ] 相互替代的课程方案通常属于同一购买决策，不按课程名称机械拆分。
- [ ] 同课程重新咨询不能仅按名称或间隔天数自动决定新建／恢复。
- [ ] 默认突出一个当前机会是展示规则，不作为禁止多个真实机会的硬限制。
- [ ] 多个未结束机会时，不静默选择依据归属；具体选择方式待确认。
- [ ] 明确“结束推进”与“已报名”后的恢复边界，不能通过恢复操作抹除已成立报名事实。

## 4. 最小信息范围

- [ ] 所属客户。
- [ ] 本次课程／购买需求，允许“课程待确认”，不猜测课程。
- [ ] 当前七阶段及阶段版本。
- [ ] 创建、阶段变更、结束记录及时间。
- [ ] 创建人、阶段操作者、原文依据及阶段历史。
- [ ] 历史事实与当前展示投影的关系。

暂不增加预测金额、赢单概率、预计成交日期、复杂产品明细、审批或独立看板。暂保留一个客户负责人，不新增机会负责人体系；转交权限与历史沿用现有规则，细节需评审。

## 5. 页面与记录入口

- [ ] Lead列表保留四列，销售进展显示本次课程／需求及阶段。
- [ ] 有价值时展示既有报名关系，明确对应课程，不堆叠生命周期标签。
- [ ] 跟进页突出当前机会；历史机会按需展开。
- [ ] 记录进展默认关联当前机会；一般客户信息允许仅关联客户，不强制归入机会。
- [ ] 新机会入口作为次要操作；从进展记录发起时带入原文，避免重复填写说明。
- [ ] 客户资料页仍负责基本资料与学习需求，不重复放阶段编辑或新增生命周期表单。
- [ ] 已完成里程碑保留实际发生时间与依据，并在适用时注明课程／机会。
- [ ] 系统记录机会关联历史；误关联如何更正及审计保留方式待确认。

## 6. 统计和业务边界

- [ ] 客户数、机会数、正式报名数分开，复购不计为新增客户。
- [ ] 阶段分布按机会统计；客户列表筛选、客户数量与机会数量不混用。
- [ ] 首次登记自动承接不代表高购买意愿，不自动改变Tier。
- [ ] 不新增自动任务；保留既有首次跟进要求与轻量客户约定。复购／恢复不擅自重置首次期限。
- [ ] 不重放历史通知；机会创建是否需要通知另行确认，默认不增加通知行为。
- [ ] 权限、客户归属、身份隔离和原文访问范围不能因机会关联而扩大。
