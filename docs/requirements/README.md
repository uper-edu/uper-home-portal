# 待实施需求

本目录保存尚未实施的需求及决策。这里的方案不代表当前系统行为，也不构成实施、迁移、推送或部署授权。

- `backlog/`：待讨论、待排期的需求，文件使用稳定的英文语义名称。
- 每份需求标明状态、讨论日期、范围、待确认事项及验收清单。
- 实施并验收后，在原文件记录交付依据，更新对应现行需求和操作文档，避免出现两套有效口径。
- 当前已实现的CRM规则仍参见[CRM需求](../crm/CRM-REQUIREMENTS.md)。
