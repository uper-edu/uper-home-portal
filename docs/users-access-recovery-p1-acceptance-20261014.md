## 交付范围

- 恢复授权绑定已有账号、精确 MySQL 目标、有效期、是否允许重新启用／恢复系统管理权限；恢复备份时绑定备份校验值。签名文件默认一小时有效，私密保管。
- 两条授权路径：已认证完整管理员提前签发；全部管理员无法登录且无有效预授权时，由可信主机操作员使用独立可信授权清单、分开保管的校验值、外部审批编号及审批人，精确确认后签发。后者只允许清单中原有的完整管理员，不能任意提升普通账号。

- 放行撤销会话并明确要求重新登录；历史通知暂停记录保持不变，不回放失败或未知通知。

## 发现并修复的问题

- MySQL JSON键顺序会变化：签名及目标比较先做规范化，避免合法重试被误拒绝。
- 旧恢复凭证可能随备份被复制：结果查询和重试按目标及恢复实例区分历史，不能显示为本次恢复成功。
- 放行后再次普通恢复不能丢失已放行实例ID，否则结果会被误判为历史。
- 逐人复核此前未提交所见授权快照；现已绑定并拒绝陈旧页面，刷新后重新确认。
- 放行撤销会话后不再立即使用旧会话加载接口并报失败；改为明确重新登录反馈。
- “只有一小时预授权”的流程不足以处理突然全员失联；新增受可信独立清单约束的离线应急审批，未准备可信证据时仍拒绝。
- 浏览器恢复门禁期间应只查询结果，不能混入签发准备表单；增加三语渲染回归。Node测试的CSS导入处理已补齐，属于测试加载修正。
