# CRM客户切换与页签保持验收

日期：2026-10-17（America/Vancouver）。仅独立4426；未切换3000、未推送GitHub、未部署服务器。

## 实现

普通客户入口（左侧姓名／整行、上一位／下一位）共用打开逻辑：面板已打开时保留当前页签；首次进入默认跟进。再次点击当前客户是无操作，不改变草稿和阅读位置。显式任务、消息、测评和购买信号入口仍采用传入的目标页签。

跨客户切换先经过原有草稿确认及提交中保护。离开时可继续编辑，或明确放弃后切换。切换后清理任务、消息与信号定位以及表单上下文，内容区按客户ID重建；阅读从顶部开始，姓名标题获得焦点。普通页签切换保持面板位置，定向入口继续定位具体内容。

对话查询继续使用AbortController终止过期请求，并为查询结果保存所属客户ID；只渲染与当前客户一致的数据。内容区按客户ID重建，局部折叠、历史会话选择、输入等状态不跨客户复用。没有改变任务、权限、分类或评分规则。

英文、印尼文、中文在线手册新增一致的客户切换说明；沿用现有三语草稿确认及加载提示。
