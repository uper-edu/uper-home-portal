日期：2026-10-17。范围：独立MySQL、模拟Sales及模拟客户，127.0.0.1:4426。

## 实现

1. 客户与联系方式：姓名、WhatsApp、邮箱、客户身份、已有家长联系方式；首选沟通语言是本章最后一项，原保存控件与权限不变。
2. 学习需求：学习目标、城市、授课方式、自报水平。
3. 销售进展：原Owner和阶段控件，以及有原始记录时直接可读的业务结果。
4. 客户分组：独立且始终展开，标题旁显示当前值，购买信号紧接在下面，之后直接展示既有分组来源、辅助分组与更新时间。
5. 获客来源与活动记录：原Campaign／来源、登记时间、来源追踪及活动历史；可选参与编辑仍是同级入口，没有嵌套折叠。

客户分组按用户最新要求改为独立常显章节，替代原折叠区；没有箭头、折叠或分组编辑控件，不产生分组修改。无已保存分组时显示未记录，不默认设为高意向。已有辅助分组保留，空辅助字段继续隐藏。

业务结果依据实际已保存字段展示：结果、班级、金额各自按有值显示；数字零保留为零，不把缺失金额补零，不从销售阶段推断付款。全部为空时不渲染结果区。没有新增结果编辑入口或改变业务判定。

三语界面及在线操作指南同步。顺带纠正本区两项印尼文购买信号的表达为“Menanyakan biaya／Menanyakan jadwal”。人名、原始班级名称、客户消息和人工备注不翻译。
