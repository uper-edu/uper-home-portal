## 实现与兼容

1. 新策略 `calendarMode=inherit`，动态读取全局 SLA 工作日历。新事件排队和每日汇总生成使用该日历；新继承任务发送前再次检查工作限制。
2. 旧策略未带 mode 且日历与旧标准默认值相同时，读取为继承；旧自定义日历保留 custom。旧排队快照缺少 mode 时，继续沿用原日历；不重算跟进截止时间、不提前重排旧任务。
3. 仅 Lark 或每日汇总需要发送时间区。汇总时间只在 daily.digest 或 digest 发送模式下出现；自定义时区/工作日/起止时间按需显示。站内普通提醒不再显示无效日历限制。
4. 时间预览按实际日历计算，结果带策略时区；每日汇总的站内预览为汇总事件生成时间。切换条件清除旧预览。
5. 渠道和群选择器显示管理员填写的群名称、团队名称及服务端连接状态。内部别名 sales 不再作为群名称呈现。未命名或未配置渠道明确标识。
6. 连接状态检查区分模拟、缺少 Webhook、缺少签名密钥、测试群受限、配置就绪但实收未确认；不返回密钥、不把配置就绪宣称为员工已读或群内收到。
7. 默认策略 ID 如 lead.created 原来被前端 ID 校验拒绝；现允许点并已通过浏览器保存验证。
