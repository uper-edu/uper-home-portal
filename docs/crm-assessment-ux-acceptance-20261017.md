# CRM测评展示与常用沟通模板验收

日期：2026-10-17。范围：CRM展示、沟通预览及英文／印尼文／中文在线文档。未切换3000、未推送GitHub、未部署服务器。

## 交付

1. 测评页使用结果概览、学习背景、作答表现、可展开的测评依据与历史记录。结论优先，分数与运营时区明确，正确／跳过／未答为0时如实展示，分项固定按听力、阅读、书写题目排列。
2. 完整测评按已经保存的thresholds展示“达到本卷HSK标准”，不再统一添加“暂定”或要求顾问例行批准。快速测评继续表达起点建议；边界、缺答、表现不一致及音频异常按已保存原因解释。缺少或不一致的结构化依据不凭总分推断等级。
3. 教师定级、最新测评、自报分别呈现。教师和定级日期未记录时明确缺失，不从测评或登记时间借用。
4. Original saved notes更名为原始测评说明，置于测评依据与历史记录的第二层折叠区。保留客户级原文，不冒充销售备注或已核实的最新作答说明，不删除历史、不自动翻译原文。
5. 联系预览新增五种可编辑模板：初次联系与需求确认、测评结果沟通、课程与排期沟通、试听需求沟通、报名协助；另提供自由编写。原有选中销售指导入口保留。模板不是Offer目录，不承诺未核实的价格、优惠、席位或试听安排。
6. 模板使用客户明确选择的沟通语言，员工界面语言切换不改写草稿。替换已编辑内容前须确认；保留和替换操作后焦点返回编辑框。未知语言、空内容、待确认替换及停止联系时不能复制／发起WhatsApp。
7. 修复联系预览只占容器半宽的问题；语言和模板各有可见标签，桌面并列、窄屏纵向排列，沿用标准CRM下拉。
8. 三语操作指南与系统说明同步，解释自动评分与测评范围、原文来源限制、模板使用和不自动完成任务的边界。

- 现有教师记录缺少教师／时间的情况只能显示未记录，不补造资料。
- 模板为静态编辑起点，未接入正式Offer目录、即时班级容量或优惠审批，也不自动引用客户分数。
- 测评覆盖范围、评分规则和学习起点算法保持原样；展示更清楚不代表新增正式HSK认证或完整口语能力评估。
- 本轮为模拟销售角色验收，没有真实销售效率测量、跨浏览器认证或正式无障碍认证。
