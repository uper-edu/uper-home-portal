# 管理表单字段规范

CRM、CMS、系统管理共用 AdminField、AdminFieldLabel、AdminRequiredNote；原生提交表单可用 AdminForm 作保存前检查，业务写入仍由原处理器负责。

- 必填：字段名＋*；表单现有表单标题旁“* 必填”，不单独占行。不以红色作为唯一提示。星号对屏幕阅读器隐藏，控件使用原生 required／aria-required，标签与控件关联。
- 选填：无星号，不显示“选填／可选／optional／opsional”后缀。不能改写用户输入或已保存内容。
- 条件必填：条件成立时显示星号并校验；条件不成立的隐藏值不阻断提交。禁用、只读以及“留空保持原值”的输入不误标。
- 下拉框、单选和复选组选值要求与业务保持一致；要求至少选一个不等于每个选项都必选。复选框开关不默认成为必填。
- 只统一现有必填规则。用户角色可清空、登录邮箱可留空、角色职责说明可留空等业务规则不因统一外观而改变。
- 缺必填禁止保存／更新，聚焦缺项并给出可读错误；失败保留草稿。结果未知使用原结果查询，不绕过校验重写。客户端检查不能替代服务端校验。

验收：中文电脑端抽查必填空白、合法值、选填空白、条件开关、禁用字段；确认错误提交不写入。检查星号不重复、标签关联及键盘焦点。其他语言与设备按本次授权范围报告，不自动扩大测试。
