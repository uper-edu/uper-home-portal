# 验收矩阵
默认只在本地3000开发和验证，使用模拟角色与记录并保留已有数据和配置；不自动停worker或改变通知模式，不重放历史通知。危险写入、故障注入及不可控通知不能直接在3000执行；确需独立MySQL／服务时先说明原因与范围并获用户明确确认后再启动。
默认仅中文电脑端。下列三语、390px、窄屏或移动端条目为按需扩展项，只有用户明确要求才执行；未授权时保留设计要求并标注未验证，不扩大测试范围。
运营、Lead、CMS三类样板；按改动选取1280/1440/1920等桌面宽度及必要低高度场景，中文浅深色。无需机械覆盖全部尺寸；三语与移动端按上述扩展门槛执行。
路由刷新前后退、目录定位、返回筛选/滚动、选中可见、草稿跨主题、后台刷新、保存失败/未知、重复点击、离开确认。
模拟System Administrator/CRM Manager/Sales/CMS Operator/无权限；验证服务器拒绝越权。保存前后核对任务期限及通知队列。
键盘页签/菜单/弹层焦点返回，无整页溢出；文字4.5:1大字/必要边界3:1实测。
定向行为测试、受影响的持久化测试、必要的完整测试、lint、构建、diff检查；独立MySQL及其他环境遵循上述确认门槛，普通单元测试和lint不等于另起环境；报告未验证项，不声称真实效率提升。发布另授权。

回归目录切换：鼠标点击可见标题时window.scrollY与目录scrollTop稳定；键盘焦点可见且无强制对齐；窄屏关闭目录后标题可见，Escape回到目录按钮。检查长短内容与加载空态切换。核实预设、模拟器、架构图和重置入口均可找到，通知不显示无关工具。

滚动串联回归：长目录/无需滚动的短目录，顶部继续向上、底部连续向下，验证目录scrollTop夹紧且window.scrollY与右侧位置不变；移到正文后可正常滚动。测试方向键、PageUp/Down、Home/End、Tab/Enter与Escape，包含390px面板。浏览器滚轮与真实触控板惯性必须分别报告，不能以合成事件或CSS属性存在冒充触控板实机通过。

紧凑保存头：滚到长表单中段/末尾，保存与取消仍可见且只有一组；普通字段不被遮挡，键盘焦点可见。测试390px三语换行、策略当前主题保存范围及其他主题草稿、通知启用/停用草稿及渠道各自保存、成功/失败反馈；正文滚动前后对比目录scrollTop，而非只看吸顶外框位置。

五模块滚动专项：Lead/Campaign长列表和长正文分别滚到上下边界，另一侧scrollTop及window.scrollY不变；PageUp/Down、Home/End相同。记录选择只移动记录列表，表单与页签按键不被抢占。运营/文档/CMS正文滚动使window.scrollY变化但目录scrollTop保持；目录边界不带动window。检查动态页头、可用高度360px两侧及390px单视图。通知五主题逐项检查标题/操作/空态/长表单，不以左侧入口完成代替右侧完成。

按主题保存回归：同时修改A/B主题，保存A后B草稿及目录标记保留；A无修改时保存禁用。不同管理员保存不同主题均成功，同主题冲突保留草稿并核对最新值后明确继续。后台刷新/保存期间编辑不得覆盖输入。模拟事务第二写失败应回滚第一写；相同提交十次只记一次成功变更；丢响应只读核对，不自动重写。拒绝跨主题及元数据注入、拒绝普通Sales保存；任务期限/归属/通知配置与队列不变。通知策略/渠道原保存动作另行回归。

表单专项：必填标识、required／aria-required和真实校验一致；缺项不保存、不更新、不清空草稿；无星号可留空；条件关闭不校验隐藏字段；用户输入不被标签清理函数改写。核对客户端与服务端，至少覆盖原生输入及自定义下拉。

复杂编辑抽屉：实际打开准备联系、进展、资料批量编辑和补充／修正，检查同款关闭图标、标题与客户上下文、正文单独滚动和单组底部操作；短字段不强制转为抽屉。空必填不写入，关闭草稿后继续编辑内容不丢失，结果未知不可冒充成功或自动重提。跨来源画像分别验证采用、相容补充、明确变化、真实冲突；顾问请求按原始事件去重，兴趣/否定/条件不得生成请求。AI完成与字段采用正确必须分别报告。只在3000中文电脑端验证，其他语言/移动端不得自动扩展。

颜色专项：执行docs/design/admin-color-system.md。实测浅深色的普通文字≥4.5:1、必要控件／焦点≥3:1；验证保存未知琥珀与失败红、联系三结果、七阶段、停止联系、Tier中性、AI紫色及CMS／账号启用状态。颜色不得成为唯一含义。鼠标悬停与键盘聚焦保留结果语义，焦点可见；无权限入口不渲染、不进入Tab顺序，认领前置步骤有可见且关联的原因，经理不被强加认领。核对营销配色不能影响管理状态；不为验色制造真实故障、通知或业务写入，危险场景仍需独立环境授权。记录实际页面验证与组件测试的边界。
